# kechengbiao

## 项目简介

kechengbiao 是一个静态HTML网站，已部署到 Vercel。

## 访问地址

- Vercel 部署地址：https://kechengbiao-xxx.vercel.app
- GitHub 仓库：https://github.com/ZBJDSBJ/kechengbiao

## 项目结构

```
kechengbiao/
├── 课程表.html    # 主页面
├── index.html            # 入口重定向
├── vercel.json           # Vercel 部署配置
├── .gitignore            # Git 忽略规则
└── README.md             # 项目说明（本文件）
```

## 本地开发

直接在浏览器中打开 `课程表.html` 即可预览。

## 部署

代码推送到 GitHub 后，Vercel 会自动检测并重新部署。
